# JACOB TROIT — KBLY 1610 AM

The official, unofficial, deeply unnecessary website of Jacob Troit of Bremerton, Washington.
Home of KBLY 1610 AM and Billy, the voice in the radio (an ElevenLabs conversational agent).

- `npm run dev` — local dev server
- `npm run build` — production build to `dist/`
- Pushes to `main` deploy automatically to GitHub Pages via `.github/workflows/deploy.yml`.

Type "steve" anywhere on the page. See what happens.
